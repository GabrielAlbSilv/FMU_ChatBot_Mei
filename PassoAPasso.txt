1. Crie a pasta do projeto e coloque nela os arquivos (incluindo os PDFs numerados, ex.: 1-Cartilha_MEI.pdf)

2. Abra a pasta do projeto no VS Code
		2.1 Instale o Python, comando:
			winget install 9NQ7512CXL7T -e --accept-source-agreements --accept-package-agreements --disable-interactivity

3. Crie o arquivo .env (use o .env.example como modelo):
		GROQ_API_KEY="ChaveApiAqui"

4. Abra o terminal (ctrl '), crie e ative um ambiente virtual:
		1: python -m venv venv
		2: .\venv\Scripts\Activate.ps1 (após a ativação, deverá aparecer (venv) no início da linha do terminal)
		3: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass (se o Windows não permitir a ativação)

5. Instale as bibliotecas:
		python -m pip install -r requirements.txt

6. (Opcional) Gere o índice dos PDFs antes de iniciar. Se pular, ele é gerado na primeira execução:
		python preparar_base.py

7. Inicie o servidor:
		python app.py
	Abra no navegador: http://localhost:5000  (página inicial)  e  http://localhost:5000/chat  (chat)

8. Logo da FMU: fica em static/logo-fmu.png (imagem com fundo transparente).
